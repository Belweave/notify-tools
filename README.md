# Notify Tools

Tools for connecting your software and agents to [Notify](https://notify.belweave.ai).

CLI, microAuth SDK, connectors, and agent integrations. Versioned downloads are distributed through [GitHub Releases](https://github.com/Belweave/notify-tools/releases).

See the [Notify documentation](https://notify.belweave.ai/docs) for product guides and the HTTP API.
